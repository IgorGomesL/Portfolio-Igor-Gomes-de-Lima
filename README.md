# 💻 Portfólio Pessoal - Aplicações Web e Móveis

Este projeto foi desenvolvido como trabalho acadêmico para a disciplina **Aplicações Web e Móveis**, do curso de **Bacharelado em Engenharia de Software** da **Uninter**.

## 📌 Sobre o projeto

O objetivo deste trabalho é a criação de um **portfólio pessoal responsivo**, utilizando apenas tecnologias fundamentais da web:

- HTML5
- CSS3
- JavaScript (puro, sem frameworks)

O site apresenta informações pessoais, formação acadêmica, projetos desenvolvidos e um formulário de contato com validação.
